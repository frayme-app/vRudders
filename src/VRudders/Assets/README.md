# VRudders artwork

- `vrudders-mark.svg`: original rotor and split-yaw-chevron design created for this project.
- `vrudders-mark.png`: 256 px preview of the mark.
- `vrudders.ico`: transparent 32-bit icon with 16, 20, 24, 32, 40, 48, 64, 128, and 256 px frames. Rebuild these three files with `scripts/Build-Icon.ps1`.
- `helicopter-header.png`: illustration generated with the built-in imagegen tool on 2026-09-27. No existing artwork or game assets were supplied as references. Embedded in the app; no runtime download.

Original project assets are distributed with the project's MIT license. The prompt records the intended fictional subject and absence of game branding; no game or aircraft manufacturer affiliation is implied.

## Final illustration prompt (built-in imagegen)

Use case: stylized-concept. Asset type: wide decorative header illustration for an independent Windows rudder-pedal control app. Create one original fictional armed helicopter in dynamic three-quarter flight, firing its chin-mounted guns with short bright orange muzzle flashes and a few restrained tracer streaks. Original aircraft design, not a recognizable real aircraft model or anything from an existing game or franchise. Premium painted aviation concept art, crisp angular silhouette, atmospheric depth, dark petrol/navy dusk clouds and cyan rim light, warm flashes. Wide 3:1 landscape composition (1536 x 512 if possible). The aircraft and muzzle flashes occupy the RIGHT 60 percent; the LEFT 40 percent is quiet nearly solid deep navy with soft atmospheric texture, reserved for app title text added separately in code. Keep the entire rotor silhouette within the image and substantial upper/lower breathing room so the header can scale. No text of any kind, no words, no insignia, no emblems, no brand marks, no watermark, no flags, no game references. No people, victims, targets, blood or gore. Make it exciting, polished, and distinctly original. Deliver the artwork alone, not a UI mockup.
